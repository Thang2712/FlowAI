# FlowAI – Landing Page 

A landing page for **FlowAI**, a fictional AI-powered task management app.
Built with semantic HTML5 and pure CSS as a front-end practice exercise.

## Highlights

- **No classes or IDs.** Every element is styled through structural selectors
  (`:first-of-type`, `:nth-of-type()`, `:nth-child()`, descendant/child combinators).
- **CSS Grid & Flexbox** for every layout: the hero with its checklist card,
  the 3-column feature and pricing grids, and the multi-column footer.
- **Pseudo-elements for decoration.** Icons, checkmarks and star ratings are
  added with `::before` instead of extra markup.
- **CSS counters** generate the numbered steps (01, 02, 03).
- **Gradient call-to-action** section using `linear-gradient`.

## Sections

1. Header & navigation
2. Hero with stats and a sample to-do list
3. Features (6 cards)
4. How it works (3 steps)
5. Pricing (Free / Pro / Team)
6. Testimonials
7. Call to action
8. Footer

## Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, pseudo-elements, counters)

## Getting Started

Clone the repo and open `idx.html` in your browser.
No build step required.
